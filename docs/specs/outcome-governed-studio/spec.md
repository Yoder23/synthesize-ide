# Repository-specific implementation specification

## Product boundary

Assist remains the direct human-to-agent IDE. Studio and Dream add backend-owned durable initiatives around the same trusted operation, patch, command, audit, and context boundaries. No model operation is itself authority.

## Vertical slices

1. Add forward-only SQLite migrations and repositories for initiatives, specs, intent records, artifacts, roles, tasks, evidence, mandates, worktrees, events, and Pulse snapshots.
2. Add backend state machines, permission checks, artifact validation, evidence gates, budgets, verdict routing, and proof-report generation.
3. Add versioned role profiles, deterministic role context selection, serialized scheduling, and multi-role fake fixtures.
4. Add a validated allowlist-only UX prototype document and trusted React renderer using component-local state.
5. Add a Git worktree manager that owns path derivation, base binding, status/diff, and safe cleanup; it exposes no merge operation.
6. Add symbolic Pulse detectors, rule-based temporal observation, and a feature-gated shadow-only liquid observer with version/checksum/calibration validation.
7. Add thin Tauri commands and a mode-aware workspace with Overview, Intent, Dreams, UX, Architecture, Plan, Team, Pulse, Evidence, and Changes.

## Completion semantics

Implementation completion is evidence-gated. Outcome status is separate. An approved requirement cannot become verified without all required passing evidence. Frozen spec versions are append-only. Dream ideas are options until promoted. Human approval remains required for scope, prototype worktrees, patches, commands, and merge outside Synthesize.
