# Synthesize v19.2 Personal-Production Candidate

Synthesize v19.2 is a no-feature-creep stabilization pass after v19.1.

The goal is to make the personal local-model coding loop clearly documented and release-gated:

```text
Open repo
→ chat with local model
→ receive typed patch
→ review diff
→ validate/approve/apply
→ run safe local tests/builds/lints
→ send output back to agent
→ receive repair patch
→ repeat until green
```

## Current status

v19.2 should be treated as a personal-production ready candidate, not a final verified production build, until:

```bash
pnpm install
git add pnpm-lock.yaml
./scripts/release-check.sh
```

passes in a real dev environment with Rust/Cargo and pnpm.

## Why this is close

The high-risk v19 addition was user-entered command execution. v19.1 hardened that path with a strict Personal Terminal policy:

- explicit allow rules only
- unknown commands blocked
- no allowlisted-program fallback
- user flags cannot downgrade risk
- dangerous Git/network/mutation commands blocked

v19.2 documents that security posture throughout the README, production-readiness docs, known limitations, release checklist, and security policy.

## Command pathways

### Agent patch pathway

The model proposes typed operations. The backend validates, snapshots, approves, applies, rolls back, and audits.

### Governed Task pathway

The backend detects test/build/lint commands and stores approved command snapshots. Execution uses the stored snapshot, not raw frontend command content.

### Personal Terminal pathway

The user may enter only strict safe local iteration commands such as tests, builds, lints, `rg`, `ls`, `cat`, `git status`, `git diff`, and `git log`.

### Git mutation pathway

Git mutations are not Personal Terminal commands. They belong in explicit Git UI flows that can show the resulting diff and audit the action.

## Required smoke tests

```text
Fake runtime patch loop passes.
Real local model patch loop returns a patch.
Context Sent to Model displays exact context.
Patch validates, approves, applies, and rolls back.
Personal Terminal allows pnpm test, cargo test, pytest, git status.
Personal Terminal blocks git add, git checkout, node script.js, pnpm exec, curl.
Terminal output can be sent back to Agent Chat as a repair prompt.
```

## Final label

After the lockfile is committed, the release gate passes, and the smoke tests pass, this build can be called:

```text
Personal-production ready for local-model AI coding on personal repos and clean Git branches.
```
